"""
1-2 章 基础语法
一、知识点
1. 标识符规则：只能字母/下划线开头，仅包含字母数字下划线，不能是关键字，区分大小写
2. 变量动态类型：无需声明类型；无真正常量，大写仅约定
3. 基础数据类型：int整数、float浮点数、bool布尔True/False、str字符串
4. 类型转换函数：int()、float()、str()、chr()数字转字符、ord()字符转数字
5. 输入输出
   - input()：接收控制台输入，返回永远字符串
  input()：接收用户键盘输入，无论输入数字、列表、字典，全部返回字符串
  eval(字符串)：eval(input()) 把字符串当成 Python 代码执行，还原成对应原生数据类型
  
   - print()三种格式化：%、format()、f-string（考试重点）

    方式1： %
    %s 字符串（通用，万能）
    %d 整数
    %f 浮点数，%.2f 保留 2 位小数
    print("姓名：%s，年龄：%d，身高：%.2f" % (name, age, height))
    # 输出：姓名：张三，年龄：20，身高：1.75

    方式2： format( , , )
    写法1：按顺序占位 {}
    print("姓名：{}，年龄：{}，身高：{:.2f}".format(name, age, height))

    写法 2：数字编号，可重复使用
    print("{0}今年{1}岁，{0}身高{2:.2f}".format(name, age, height))

    写法 3：关键字传参
    print("姓名:{n},年龄:{a}".format(n=name, a=age))

    方式3：f-string 
    语法：字符串前加 f / F，{变量/表达式} 直接嵌入

    print(f"姓名：{name}，年龄：{age}，身高：{height:.2f}")

    # 支持直接运算
    r = 2
    print(f"圆面积：{3.14 * r ** 2}")

6. 运算符优先级（从高到低）
括号() > 幂** > * / // % > 加减 > 比较运算符 > not > and > or

7. 算术运算符：/ 除法结果浮点数；//整除；%取余；**次方

***：
逻辑运算符优先级：not > and > or；
除法区分：/浮点除、//整除
"""
什么时候才适合用 eval (input ())？

仅当题目明确要求输入列表、元组、字典这类复合容器时使用，比如：
输入一组数字存入列表，计算平均值
此时用lst = eval(input())才合理。

单纯输入数字（整数 / 小数）：必须使用float(input()) / int(input())
需要输入列表 / 字典等复合数据：才使用eval(input())
