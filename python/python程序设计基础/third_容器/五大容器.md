一、
高频易错考点
1. {} 是空字典，空集合必须写 set ()
2. 不可变容器(元组、字符串)：tuple、str，不能直接修改内部元素
3. 字典键只能是不可变类型（数字 / 字符串 / 元组），列表不能当键
4. 集合无序，不支持下标索引取值

二、
五大容器通用操作：(全部容器都能用)

1. 索引取值 [下标]
下标从0开始；负数下标代表从末尾倒数，-1是最后一个元素

2. 切片  [start:end:步长]：左闭右开；
        s[::-1]:快速反转序列

3. len(容器)：统计元素总个数

4. max() / min() :取最大、最小元素(需容器内类型统一)

5. x in 容器：成元判断，返回True、false

6. 解包：a,b,c = [10,20,30],一次拆分容器赋值变量


三、
分容器专属方法
1.  list列表(可变序列)

增加元素：
>>>append(内容)：把内容作为整体追加到末尾
例：[1,2].append([3,4]) → [1,2,[3,4]]
>>>extend(容器)：拆分传入容器，逐个添加元素
例：[1,2].extend([3,4]) → [1,2,3,4]
>>>insert(下标,元素)：在指定下标位置插入元素

删除元素：
>>>pop(下标)：
删除指定下标元素，无参数默认删最后一个，有返回值
>>>remove(元素)：
删除第一个匹配元素，元素不存在则报错
>>>clear():  清空列表全部内容

2. tuple元组(不可变,无增删改方法)
>>>仅支持：
索引、切片、max/min、len、in
>>>单元数元组格式(带逗号)
(6,)  而(6)是数字
>>>用途:函数多返回值、存在不允许修改的固定数据

3. str字符串(不可变序列)
>>> .split("分隔符")---列表
按符号切割字符串，返回列表

>>> "连接符".join(序列)---字符串
把序列用连接符拼接成完整字符串

>>> .strip()---去空
去出字符串首尾空格;Istrip左空格、rstrip右空格

>>>find(子串)
查找子串下标，无则返回-1

>>>replace(旧字符,新字符)
全局替换文本内容

4. set集合(无序、自动去重)

集合四大运算：
>>> & 交集：两个集合共有的元素
>>> | 并集: 两个集合全部元素,自动去重
>>> - 差集：只存在与第一个集合的元素
>>> ^ 对称差集： 只单独存在其中一个集合的元素

增删方法：
>>>add(元素): 添加单个元素
>>>discard(元素)：安全删除，元素不在不会报错
>>>remove(元素):  强制删除，元素不存在直接报错

四、三大推导式
作用：一行代码快书生成列表/集合/字典

1. 列表推导式
[表达式 for 变量 in 容器 if筛选条件]
示例：生成 1~20 所有偶数
even_list = [x for x in range(1,21) if x % 2 == 0]

2. 集合推导式
{表达式 for 变量 in 容器 if 筛选条件}
示例：列表快速去重
new_set = {x for x in [1,1,2,2,3]}

3. 字典推导式
{键表达式:值表达式 for 变量 in 容器 if 筛选条件}
示例：交换字典键值（值无重复时可用）
new_dict = {v:k for k,v in old_dict.items()}



五、复习区分易混考点（错题集中区）
1. append vs extend
append：整体打包添加；extend：拆分逐个添加
2. remove vs discard
remove（集合）：无对应元素报错；discard（集合）：无元素不报错
3. 可变 / 不可变
可变（可原地修改）：list、set、dict
不可变（修改只能生成新对象）：tuple、str
4. 空容器区分
空列表[]、空元组()、空字符串""、空集合set()、空字典{}


一、排序相关：
sort () 方法 VS sorted () 内置函数

1. list.sort()
仅列表可用，元组 / 字符串 / 集合无此方法
原地修改原列表，无返回值
a = lst.sort() 结果为 None
参数：
reverse=False 默认升序；reverse=True 降序
key=函数：自定义排序依据（如 key=abs 按绝对值排序）

2. sorted (可迭代对象)
通用：列表、元组、字符串、集合、range 全都支持
不修改原数据，返回全新排序列表
同样支持 reverse、key 参数

二、反转相关：
reverse () 方法 VS reversed () 内置函数 VS 切片 [::-1]
1. list.reverse()
仅列表可用，原地颠倒顺序，不排序、无返回值
不可逆容器（元组、字符串）没有该方法

2. reversed (序列)
通用：list/tuple/str/range 均可
不修改原序列，返回反向迭代器，必须转 list/tuple/ 字符串才能输出

3. 切片 [::-1]
列表、元组、字符串通用
生成反转后的新序列，原数据不变，代码最简

不带ed后缀的为方法，修改数据本省
带ed后缀为内置函数，要赋值返回新序列
