一）标准库（Python 自带，无需 pip 安装）
turtle 绘图库
画笔基础：forward () 前进、back () 后退、left ()/right () 转向
画笔状态：pensize 粗细、pencolor 画笔色、fillcolor 填充色
填充：begin_fill () 开始填充，end_fill () 结束填充
抬落笔：penup () 抬笔无痕迹，pendown () 落笔绘图
圆弧：circle (半径，角度)；正数向左画弧，负数向右画弧
random 随机库
表格
函数	作用
random.random()	生成 [0,1) 小数
random.uniform(a,b)	生成 [a,b] 区间随机小数
random.randint(a,b)	生成 [a,b] 随机整数
random.choice (序列)	随机取一个元素
random.sample(seq,k)	不重复取 k 个元素
random.shuffle (列表)	原地打乱列表，无返回值
random.seed (数字)	固定随机种子，每次结果一致
time 时间库
time.time ()：1970 纪元到现在总秒数，计算时间差
time.perf_counter ()：高精度计时，差值为运行耗时
time.sleep (n)：程序暂停 n 秒
strftime (格式，时间对象)：时间格式化输出字符串
strptime (字符串，格式)：字符串转回时间对象
os、json（前面章节已学）
os：文件 / 文件夹、路径操作
json.dump () 写入文件；json.load () 读取文件
argparse：解析命令行运行时传入的参数
（二）第三方库管理 pip 命令（必背）
安装：pip install 库名
指定版本：pip install 库名==1.2.0
国内镜像加速：pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple
卸载：pip uninstall 库名
查看已装库：pip list
本地 whl 包安装：pip install xxx.whl
（三）PyInstaller 打包
作用：把.py 脚本打包成 Windows exe 可执行文件，无需装 Python 环境运行
基础命令：pyinstaller -F 脚本名.py
参数：
-F / --onefile：打包为单个 exe 文件（考试常用）
-D：生成文件夹（默认）
--icon xxx.ico 设置程序图标
--clean 清理打包缓存
打包产物 dist 文件夹存放最终 exe 程序
