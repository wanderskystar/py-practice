一、持久化基础概念
1. 内存数据程序关闭就消失；
持久化 = 把数据存到硬盘文件，下次运行可读取。
2. 分类：文本文件、二进制文件；序列化是内存对象转文件可存储格式

二、文件基础三步：打开->读写->关闭
1. open()语法
f = open(文件名,模式,encoding="utf-8")
>路径：Windows 用r"路径"或双反斜杠"c:\\test.txt"防止转义
>encoding：文本文件必须指定 utf-8，否则中文乱码

2. 核心打开模式(重点)
模式	功能	注意
r	只读（默认 rt）	文件不存在直接抛 FileNotFoundError

w	覆盖写入	文件不存在新建；存在直接清空原有内容

a	追加写入	文件末尾新增内容，不删除旧数据

rb / wb	 二进制读 / 写	 图片、视频、序列化数据，不用写 encoding

+	读写拓展，如 r + 可读可写	

3. 文件读取方法
·read()：一次性读取全部内容,返回字符串

·readline()：读取一行，包含换行符

·readlines()：读取所有行,返回每行组成的列表

·直接for line in f：逐行遍历,节省内存

4. 文件写入方法
·write("字符串")：写入一段文本,不会自动换行,需手动加\n
·writelines(字符串列表)：批量写入多行,同样不自动换行

5. with上下文管理器(推荐)
作用：代码快结束自动关闭文件,不用手动调用f.close(),避免忘记关闭造成数据丢失
with open("a.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
# 出缩进自动关闭文件

三、os与os.path工具模块
1. os常用
    >os.getcwd()获取当前目录
    >os.mkdir()创建单层文件夹
    >os.makedirs()递归创建多层
    >os.remove()删除文件;
    >os.rmkdir()删除空文件夹
    >os.listdir("路径")返回文件夹内所有文件名称列表

2. os.path常用
>os.path.exists(path)
     判断文件 / 文件夹是否存在
>os.path.abspath(path)
    获取绝对路径
>os.path.getsize
    获取文件字节大小

四、序列化(内存对象 <-> 文件)
1. json(通用文本格式,跨语言,只支持简单类型:字典、列表、数字、字符串)
>限制：不能序列化自定义类、集合等
>写入文件：json.dump(数据, 文件对象)
>读取文件：数据 = json.load(文件对象)
>内存转换：json.dumps()转字符串 / json.loads()字符串还原数据
2. pickle(python专用二进制)
支持所有python对象(自定义类也可以),文件乱码，只能 Python 读取
>写入：pickle.dump(data, f) 模式 wb
>读取：data = pickle.load(f) 模式 rb

五、易错点
1. w 模式每次打开清空文件，追加内容必须用 a；
2. 中文乱码：文本 open 必须加encoding="utf-8"；
3. json 无法存储自定义类实例，复杂对象用 pickle；
4. 不用 with 时，操作完必须 close ()，否则缓存数据没存入硬盘；
5. readline、readlines 自带换行符，打印会多出空行
