一、 函数五大参数
1. 位置参数
调用按顺序一一对应，不可打乱顺序
def f(a,b):pass
f(1,2) # a=1,b=2
2. 关键字参数
调用指定参数名，顺序随意；位置参数必须写在关键字参数前面
f(b=2,a=1) 合法
f(1,b=2)    合法
f(a=1, 2)   语法错误
3. 默认参数
定义时直接赋值，不传参使用默认；

带默认参数必须放在无默认参数后方。

坑：默认值为可变对象（列表）时，多次调用会共用同一个对象。
def touch(a, lst=[]):
    lst.append(a)
    return lst
# 连续调用会累加数据，属于经典错题

4. 不定长位置参数 *args(打包元组)
接收任意多个位置实参，自动打包为元组 tuple，只能放在普通、默认参数之后
收集所有多余的位置实参.*args 之后，不能再写普通位置参数，只能写「仅关键字参数」。
定义函数时*args是打包，函数内部*args是解包
def sum_all(*args):
    print(args) # 元组

5. 不定长关键字参数 **kwargs
收集所有多余的key=value关键字实参，打包成字典；
只能放在所有参数的末尾，后面不能再加任何参数。
接收任意多个 key=value 实参，自动打包为字典 dict，必须放在所有参数最后

参数标准书写顺序：
普通位置参数 → 默认参数 → *args → 仅关键字参数 → **kwargs

6. 实参传递底层规则
不可变类型（int/str/tuple）：函数内修改副本，外部原值不变；

可变类型（list/dict）：函数内原地修改，外部同步变化；仅给形参重新赋值不影响外部

二、 匿名函数 lambda(没有名字只能写一行的临时函数)
1. 语法：
lambda 参数列表 : 单行表达式

2. 限制：只能一行运算，
不能写循环、if 分支块；
自带 return，表达式结果自动返回

3. 等价 def 写法
f = lambda x,y:x+y
# 等价
def f(x,y):
    return x+y

4. 常用于：列表sort排序key参数
stu = [("张三",80),("李四",90)]
# 按分数降序
stu.sort(key=lambda x:x[1], reverse=True)
# sort会取出stu里面的每一项
# 第一次 x = ("张三",80)
# 第二次 x = ("李四",90)
# x代表的是列表中的每一个元素
# x[]代表取出这个元组中的元素

三、 模块(.py文件)
1. 定义：一个.py文件就是模块，去掉py为模块名

2. 导入方式
import 模块名
使用：模块。函数 ()

from 模块 import 函数1,函数2
使用：直接调用函数名

import 模块 as 别名（推荐，简化书写

3. if __name__ == "__main__" 作用
·模块直接双击运行：__name__ = "__main__"，内部代码执行；

·模块被其他文件 import 导入：__name__ = 模块名，内部代码不执行；
用途：区分测试代码与功能代码，导入时不会自动执行测试打印

4. 补充基础概念
>>>包：包含__init__.py的文件夹，存放多个模块；
>>>pip 命令（第三方模块管理）
pip install 库名 安装
pip uninstall 库名 卸载
pip list 查看已安装库

5. 作用域
·局部变量：函数内部定义，仅函数内可用；
·全局变量：模块顶层定义，全文件可用；
·global：函数内声明使用全局变量；
·nonlocal：内层函数使用外层函数变量。

四、全章节易混汇总
>>>无 return 函数返回None，不是 0；
>>>*args存元组，**kwargs存字典；
>>>默认参数列表会共享数据，尽量不用可变对象当默认值；
>>>lambda 不能多行代码，只支持单个表达式；
>>>if __name__ == "__main__"导入模块不会执行内部代码；
>>>关键字参数不能写在位置参数前面；
>>>可变列表传入函数，原地修改会影响外部原始列表
