Object-Oriented Programming
一、基础核心：类、对象、self、构造方法
1. 面向过程VS面向对象
·面向过程：数据、函数分开,代码零散

·面向对象：把属性(数据)+方法(操作)封装到类里，已对象为核心

·OOP四大核心特性：封装、继承、多态、抽象

2. 类与对象区分
·类Class：
事物模版/图纸,定义通用属性、方法;
class 类名: 定义,类名大驼峰
实例：
class Student: # 类
    pass
s1 = Student() # 对象/实例

3. 构造方法__init__(self)
·别称：构造函数，创建对象时自动调用,不用手动执行
·作用：给实例绑定属性,初始化数据
·规定：第一个参数必须是self,不能省略
·禁止：__init___只能返回None,别的不行
class Circle:
    def __init__(self, r):
        self.r = r # self.r 实例属性

4. self详解
·self代表当前正在创建/调用的实例对象本身
·所有实例方法第一个参数固定为self
·访问实例数据必须加self.属性名,不加就是局部变量

二、 两类属性：实例属性/类属性
1. 实例属性(对象独有)
定义在__init__内,格式self.xxx;
每个对象独立,互不干扰
2. 类属性(全类共享)
定义在类的内部、方法的外部;所有实例共用,修改类属性全部对象同步变化
class Student:
    school = "长沙工院" # 类属性
    def __init__(self,name):
        self.name = name # 实例属性
·访问： 类名.类属性 /  对象.类属性
·修改全局共享值：只能Student.school = xxx

三、 三类方法(实例/类/静态)
1. 实例方法
·标识：首参数self
·权限：可读可改实例属性、可读类属性
·调用：对象.方法()

2. 类方法@classmethod
·标识：装饰器@classmethod,首参cls(代表类本身)
·权限：只能操作类属性,不能访问实例属性
·调用：类名.方法()  / 对象.方法()

3. 静态方法@staticmethod
·标识：装饰器@staticmethod,无self、无cls
·权限：不能访问实例、类任何属性,仅独立工具函数
·调用：类名.方法()

方法  首参数 访问实例属性	类属性
实例方法 self	✅	         ✅
类方法	 cls	❌	         ✅
静态方法  无	❌	         ❌

四、封装：私有属性与访问控制

1. 命名规则：双下划线开头__sid=私有属性
2. 核心特点：类外部无法直接obj.__sid访问,实现数据隐藏(封装)
3. 标准规范：对外提供公共方法读取/修改私有数据
·get_xxx()：获取私有值
·set_xxx()：修改私有值,可增加数据校验
class Student:
    def __init__(self,sid):
        self.__sid = sid # 私有
    def get_sid(self):
        return self.__sid # 公共读取接口
4. 拓展@property装饰器：把方法伪装成属性,简化读写

五、 继承(代码复用核心)
>>>代码复用：父类以后新增属性（age、color），子类一行代码不用改，自动继承；
>>>统一维护：父类逻辑只改一处，所有子类同步生效；
>>>符合面向对象继承思想：子类只写自己独有的逻辑，公共逻辑交给父类
1. 基础语法
class 子类(父类): # 单继承
    pass
# 多继承：class 子类(父1,父2):
·父类/基类：被继承的类
·子类/派生类：拥有父类全部属性、方法,继承父类属性

2. super()函数
作用：调用父类的__init__、普通方法,继承父类属性
>>>子类构造方法必须用super()加载父类参数,否则无法继承实例属性
class Dog(Animal):
    def __init__(self,name):
        super().__init__(name) # 调用父类构造
>>>子类重写方法后,用super().方法()复用父类逻辑

3. 方法重写(实现多态)
子类定义与父类同名的方法，子类实例调用优先执行子类逻辑,覆盖父类行为
class Animal:
    def speak(self):
        pass
class Dog(Animal):
    def speak(self): # 重写
        print("汪汪汪")

4. 多继承
一个子类同时继承多个父类;查找方法遵循MRO,慎用易产生歧义

六、多态
>>>核心：同一个方法接口,不同对象执行不同逻辑
>>>条件：存在继承、子类重写父类方法；传入不同子类对象,表现不同行为
