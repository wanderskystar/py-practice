# 02-standard-lib
Python 标准库实战练习文件夹，第一周任务：文件、字符串、路径、时间、json基础操作

## 📄 文件说明
- `count_text.py`：文本统计脚本，统计文件行数、汉字数量；练习with文件读写、异常捕获、字符遍历
- `memo_tool.py`：备忘录小工具，支持输入追加保存内容、查看历史备忘录；文件追加读写、交互菜单
- `String_process.py`：字符串清洗处理，去除多余空格、提取数字、文本清理；练习split/strip/replace
- `prac_pathlib.py`：pathlib路径库练习，遍历目录、批量重命名等文件操作
- `time_demo.py`：datetime时间库练习，获取当前时间、日期差计算、时间格式化输出
- `json_io.py`：json模块读写练习，实现字典和json文件互相转换
- `memofile`：备忘录脚本对应的存储数据文件

## ✅ 环境
Python3.10+，全部脚本可以直接运行。
> 注意：批量重命名相关脚本，**务必先预览dry_run，不要直接在重要文件夹执行**，防止文件误修改。
